## Summary / Resumen

- **Problem it solves / Problema que resuelve:** A car wash that books by phone or WhatsApp loses appointments, double-books its bays, cannot tell which operator is free and has no record of the condition the vehicle arrived in. / Un lavadero que agenda por teléfono o WhatsApp pierde citas, cruza reservas en sus bahías, no sabe qué operario está libre y no deja registro del estado en que llegó el vehículo.
- **Target users / Usuarios:** customers of the car wash, wash operators and the administrator of a single-site car wash. / Clientes del lavadero, operarios de lavado y el administrador de un lavadero de una sede.
- **Main features / Funciones principales:** customer and vehicle registration; bookings with real availability by time slot and bay; payment when booking (digital with receipt or cash); automatic operator assignment; start and close of the service; inspection report with photos; in-app, push and email notifications; loyalty points and promotions; reports for the administrator. / Registro de clientes y vehículos; reservas con disponibilidad real por horario y bahía; pago al reservar (digital con comprobante o efectivo); asignación automática de operarios; inicio y cierre del servicio; informe de inspección con fotos; avisos en la app, push y correo; puntos y promociones; reportes para el administrador.
- **Technology stack / Tecnologías:** Java 21 and Spring Boot (5 microservices and the API gateway), C# and .NET 8 (payment service), Angular (web), React Native with Expo (Android app), SQL Server 2022, RabbitMQ, Liquibase, Docker and Caddy on Azure. / Java 21 y Spring Boot (5 microservicios y el API gateway), C# y .NET 8 (servicio de pagos), Angular (web), React Native con Expo (app Android), SQL Server 2022, RabbitMQ, Liquibase, Docker y Caddy en Azure.
- **Production URL / URL en producción:** https://lavarapidovehicular.northcentralus.cloudapp.azure.com
- **Demo credentials / Credenciales de prueba:** given to the instructor through the private channel / se entregan al instructor por el canal privado
