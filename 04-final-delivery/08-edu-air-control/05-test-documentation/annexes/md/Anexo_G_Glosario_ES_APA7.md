# Anexo G. Glosario

---

| Término | Definición |
|---|---|
| ADR | Registro de decisión de arquitectura: documento corto que explica una decisión de diseño y sus consecuencias |
| API | Interfaz que permite la comunicación entre aplicaciones |
| API Gateway | Punto de entrada único que enruta las solicitudes, valida el JWT y limita el tráfico |
| BFF | Backend-for-Frontend: capa de servidor adaptada a las necesidades de un cliente |
| BLE | Bluetooth de baja energía; la app móvil lo usa para aprovisionar el ESP32 |
| DHT11 | Sensor digital de temperatura y humedad del aire |
| ESP32 | Microcontrolador con Wi-Fi y Bluetooth |
| Hexagonal (arquitectura) | Estilo que separa el dominio de los adaptadores de entrada y salida mediante puertos |
| IoT | Internet de las cosas: dispositivos físicos conectados que envían datos |
| JWT | Token firmado que autentica las solicitudes de un usuario |
| JWKS | Conjunto de llaves públicas con el que los servicios verifican la firma de los JWT |
| KY-038 | Módulo de sonido con salida analógica para nivel relativo de ruido |
| Liquibase | Herramienta para versionar los cambios de la base de datos |
| MQ-135 | Sensor de gases y calidad del aire; requiere calibración y no mide CO₂ en ppm sin ella |
| MQTT | Protocolo de mensajería IoT considerado en la arquitectura; no está confirmado en el firmware |
| OAuth2 / OIDC | Estándares de autorización y de identidad usados para el inicio de sesión |
| OpenAPI | Estándar para describir contratos de API REST |
| Outbox | Patrón que guarda los eventos en la base de datos antes de publicarlos para no perderlos |
| RBAC | Control de acceso basado en roles (SUPER_ADMIN, ADMIN, USER, VIEWER) |
| Smoke test | Prueba rápida de extremo a extremo que confirma que el sistema básico responde |
| Testcontainers | Biblioteca que levanta contenedores Docker (por ejemplo PostgreSQL) durante las pruebas |
| X-API-Key | Clave con la que un dispositivo IoT se autentica al enviar mediciones |
