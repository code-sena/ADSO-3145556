# Firmware IoT

El ZIP entregado para esta versión no contiene archivos de firmware `.ino`, `.cpp` o `.h` del ESP32. Por esta razón no se copia código de firmware en esta carpeta.

Hardware declarado: ESP32, DHT11, KY-038, MQ-135, protoboard, jumpers, batería y resistencias de 10 kΩ y 20 kΩ.

Cuando se entregue el firmware, debe agregarse aquí con su README, diagrama de conexiones y versión del SDK.
