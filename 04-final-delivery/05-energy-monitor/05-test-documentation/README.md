## Notes / Notas

The evidence files are in `evidence/` inside `en/` and `es/`. The test cases are the inventory of automated tests of the test plan. The test plan also lists the known gaps, such as the mobile test protocol that is still to be run. / Los archivos de evidencia están en `evidence/` dentro de `en/` y `es/`. Los casos de prueba son el inventario de pruebas automatizadas del plan de pruebas. El plan también lista los vacíos conocidos, como el protocolo de pruebas móviles que sigue por ejecutar.

## Format / Formato

- Final version in PDF, plus the editable source (Markdown). / Versión final en PDF y su fuente editable (Markdown).
- Every document exists in English (`en/`) and Spanish (`es/`) with the same English file name. / Cada documento existe en inglés (`en/`) y en español (`es/`) con el mismo nombre de archivo en inglés.
- No passwords, tokens, keys or real user data. / Sin contraseñas, tokens, llaves ni datos reales de usuarios.
